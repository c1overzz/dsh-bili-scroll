# DS 大肥鱼聊天表情包

整理日期：2026-10-20。共 180 张原图，127,964,091 字节（约 122.0 MiB），含 4 张多帧 GIF 和 1 张单帧 GIF。文件名采用「情绪_内容.扩展名」，保留原始字节、分辨率、透明度、动画、署名和水印。

## 接入刷 B 站插件

1. 从 GitHub 源码取得本目录。素材不包含在默认 npm 插件包里。
2. 将本目录复制到后端运行环境的 `<DSH_HOME>/bili-duty/stickers/DS表情包/`，保留图片和 `表情索引.json`。
3. 将本目录的 `comment-stickers.example.json` 复制为 `<DSH_HOME>/bili-duty/comment-stickers.json`。配置应放在 `bili-duty/` 下，内容如下：

```json
{
  "directory": "stickers/DS表情包",
  "default": "乖巧_端坐等你.webp"
}
```

`directory` 相对这份配置文件解析；也可换成后端 Python 能读取的绝对路径。DSH 在 WSL 中运行时，图片也须位于 WSL 可访问的位置。配置只启用配图，发送仍受原有评论权限开关控制。

发布顶层新评论前，调用只读 `bili_stickers` 可检查是否返回 `configured=true`，再按 `emotion` 或 `query` 找候选。将返回的真实 `filename` 传给 `bili_reply(..., sticker=...)`；漏选时使用默认的端坐图。普通图片最长边转换为 768 像素的 PNG，GIF 在 B 站评论中发送静态首帧，库内原文件保留。

B站子评论不能带图。回复评论（`rpid != 0`）只发送文本与正确的 `rpid`/`root`，无需查询或选择图片；即使误传 `sticker`，也不会上传图片，回执会说明跳过原因。

## 聊天选图与索引

可按「感谢」「安慰」「开心」「晚安」等情绪检索，再核对图片台词是否符合当前对话。通常选一张即可，避免台词与正文冲突。

`表情索引.json` 逐图提供 `filename`、`emotion`、`content`、格式、动画与帧数、尺寸、字节数、SHA-256，以及来源链接。`filename` 相对本目录定位；公共索引不包含任何机器的绝对路径。其他聊天软件可使用其现有附件或表情发送功能。
