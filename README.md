# dsh-bili-scroll ｜ 刷B站

> **先看三行**
> - 需要 **dsh ≥ `0.1.7-rc.1`**（本机是 `0.1.7-rc.2`）。⚠️ 版本不满足时，**内核会静默跳过这个插件** —— 装了跟没装一样，不会报错。
> - **空间**：不装「本地转写」约 **84 MB**；装了转写约 **1 GB**（其中 Whisper 模型 538 MB，可在设置里换更小的模型）。
> - 装完**必须重启一次** dsh（插件在 bundle 层组装）。
> - ⚠️ **桌面版 DSH（NEXT / 0.2.x）**：**0.1.3 及以前的版本在桌面版上装不起来** —— 插件整条不激活，
>   DSH 只留一句 `warning: 1 entry did not activate … failed to import`（根因是宿主半 import 的两个包
>   在桌面版 profile 里没被安装，详见下面「装不上」那节的第 5 条）。**0.1.4 起已修** ✓。
>   另有用户反馈桌面版上「自动跑那一轮会卡住」—— 卡住就先只用设置页的「**现在跑一轮**」手动跑（那条稳）。
>
> ⚠️ **装的是旧版吗？** 如果设置页里那个按钮写的是「**重装依赖**」（而不是「**重装主依赖**」），说明你装的是 0.1.0 ——
> 跑一次 `dsh plugin --profile web add dsh-bili-scroll` 升级就好（那一版建 Python 环境时缺一个参数，
> 依赖装不上、二维码也画不出来，重装多少次都一样）。

> DSH 插件：**每天替你刷一轮 B站** —— 它自己搜、**读字幕原文**判断、把值得的写成报告，特别值得的会留一条评论 **@ 你**。
> **你收到的每一条 @，都是它先筛过一遍的。**

## 它做什么

- 按你填的关键词（留空则用内置那几组）搜近几天的视频
- **逐条读字幕原文再判断**（不看摘要）；拿不到字幕的默认跳过 —— 除非你开了「本地转写」或「拿不到字幕的也看看」
- 写一份 Markdown 报告到 `out/<日期>.md`：每条含「为什么值得」+「它自己的一句话」
- 开着「自动评论」时，每轮最多发一条评论、**@ 你**一次
- 可以在**你自己定的时段自动跑**（默认是 DeepSeek 的优惠时段），省 token
- **人格与语气由你定**：插件自身**不带**任何性格 —— 写一个 md 文件就是它这一轮的全部人格（位置可指定，设置页里直接改）
- **用哪个模型也由你定**：那一轮可以在设置里指定模型 / 服务商，不动你的 profile

## 装之前（一条前提，30 秒）

机器上要有 **`Python 3.10+` 或 `uv`** —— **有一个就够**：

- **有 `uv` 最好**：一个 ~32 MB 的**单文件可执行程序**（Windows 上是 `uv.exe`，Linux / macOS 上是 `uv`），
  **解压就能用、不用管理员、不用进 PATH**，而且它还能自己把 Python 拉下来；
- 只有 Python 也行（装官方安装器时记得勾 **`Add to PATH`**）；
- ⭐ **两个都没有？也没关系**：点「装依赖」时**插件会自己下一份 `uv` 放到自己的数据目录**
  （单文件、约 15MB、**免管理员、不用进 PATH** ✓），之后全程自动 ✓
  · 它会**先直连 GitHub，不通就走国内加速代理**，还配了 PyPI 镜像兜底 ✓
  · 下载完会**核对官方 `sha256`**（对不上就丢弃换下一个源 ✓）—— 因为它下来的东西是要**被执行**的
  · ⚠️ **Windows 上如果杀软 / Defender 拦了这个下载**：把插件数据目录 `%USERPROFILE%\.dsh\bili-duty\bin\` **加白**即可；
    不想加白也行，自己装一份 uv 或 Python 3.10+ 就绕过去了 ✓（Linux / macOS 上没这回事）

> ✅ **已经做到了**（v0.1.1 起）：插件会**自己把 `uv` 下到自己的数据目录** ⇒ 这条前提不用用户操心、也不用管理员权限。
> ⚠️ 万一它自己也下不动（有用户反馈桌面版上这条链路经常不通）：**手动放一份 uv 到 `<数据目录>/bin/`** 就行 ——
> Windows 上文件名是 `uv.exe`，Linux / macOS 上是 `uv`（记得 `chmod +x uv`）。
> 插件**优先用那里那一份**，会跳过下载。

## 装


```bash
dsh plugin --profile web add dsh-bili-scroll      # 从 npm
dsh plugin --profile web add github:c1overzz/dsh-bili-scroll   # 备选：直接从 GitHub
```
（⭐ 最省事的一条：把仓库链接贴给你自己的 dsh，说「**帮我装这个插件**」，它会自己装。）

⚠️ 装完**必须重启一次 dsh**（bundle 层要重启才组装）。然后进 **设置 → 刷B站**。

## 装不上 / 卡住时，先看这五条（都是用户实测撞过的）

1. **桌面版（DSH NEXT / 0.2.x）上"自动跑"会卡住** —— 有用户反馈：它起那一轮用的是
   `dsh --profile headless …`，桌面版上容易卡在那儿。⇒ **先用设置页的「现在跑一轮」手动跑**（那条是稳的）；
   能不能自动跑，等你确认过自己那台桌面版的版本与 profile 再说。
2. **「装依赖」卡住、或者扫码时一直不出二维码** —— 大概率是 0.1.0 那版（见开头那个按钮指纹，跑一次 `add` 就升级了）。
   不想升级也行，救急一句（Windows）：`<家>\.venv\Scripts\python.exe -m ensurepip --upgrade`，
   Linux / macOS 上则是：`<家>/.venv/bin/python -m ensurepip --upgrade`，再点一次「重装主依赖」。
3. **它下不动 `uv`**（桌面版上这条链路经常不通）⇒ 自己放一份 uv 到 `<数据目录>/bin/`
   （Windows 是 `uv.exe`，Linux / macOS 是 `uv`），插件会优先用它、跳过下载。
4. **「本地转写」是两段式的** —— 只打开开关**不够**，还得点它下面那个「**装转写依赖**」。
   没装的时候，拿不到字幕的视频默认被**跳过**（报告里会写「**因无字幕跳过 N 条**」，你能一眼看出漏了几条）；
   也可以改开「拿不到字幕的也看看」—— 那就只凭标题和简介判断，不再跳过。
5. ⭐ **桌面版：装完设置页里根本不出现「刷B站」，日志只有一句 `1 entry did not activate … failed to import`** ——
   这是 0.1.3 及以前在桌面版上的一个真 bug：插件宿主半 import 的两个包是 *optional peer*，
   而桌面版 profile（`autoInstallPeers: false`）**不会装它们** ⇒ 插件整条不激活。
   **0.1.4 起已修**（不再裸 import 那两个包）。⇒ 升级一次就好：`dsh plugin --profile desktop add dsh-bili-scroll`。
   ⚠️ 我们自己也只在 **npm 0.1.7-rc.x + web profile** 上实测过；桌面版这条路靠用户反馈修好的 ——
   装完还是不行的话，把 `duty.log` 里那几行发来（里面会写清楚"宿主依赖是从哪儿取的"）。

## 首次使用（两步）

1. **装主依赖** —— 设置页点「装主依赖」：在插件自己的数据目录里建一个独立 venv，装 3 个包
   （`bilibili-api-python` / `mcp<2` / `qrcode`）。**走国内镜像 + uv，通常几十秒**（进度写 `install.log`，不卡页面）。
2. **扫码登录** —— 点「扫码登录」，用手机 B站 扫页面上那张码。
   ⚠️ **确认时选「记住我 / 长期」那张**（选 24 小时的话，明天就得重扫）。
   凭证只落在你本机的插件数据目录：`<DSH_HOME>/bili-duty/bili_credential.json`，不上传任何地方。

## 设置页里有什么

| 项 | 说明 |
|---|---|
| **到点自动刷** | 总开关；**打开之后才展开时段表**。默认用内置口径（「中午谷时 12:00–14:00」「晚上/夜间谷时 18:00–09:00」，依据 DeepSeek 官方定价：**工作日 9:00–12:00、14:00–18:00 是高峰，其余（含整个周末）都是谷时**）。⭐ **也可以自己定时段**：任意多条、**24 小时制**、起晚于止就是跨到第二天（`18:00 → 09:00` 一整晚）。加了自定义就**整个接管**，内置那两组让位；点「清空 · 回内置」能退回去。**一个时段跑一轮**，重叠的两条会并成一段（只跑一轮）并在设置页给出提示 |
| **每天最多挑几条** | 数字自己填；填 0 = 不自动刷（但还能手动跑） |
| **自动评论并 @ 你** | **默认关**；打开后展开两栏：**每轮最多发几条评论**、**要 @ 谁（B站 昵称，可加多个）** —— ⚠️ **留空就不发评论**（评论的意义就是 @ 那一下） |
| **拿不到字幕的也看看** | **默认关**。开着的话：拿不到字幕（压根没字幕 / 没开转写 / 转写出来是空的）**不再直接跳过**，改看**标题 / 简介 / 播放量**判断值不值得推；🔴 但**不分析视频内容**，报告里那条会明写「没看内容，只凭标题/简介」，末尾单独统计「其中 M 条……」 |
| **本地转写没字幕的视频** | **默认关** —— 要在本机装 Whisper、下几百 MB 模型。比"只看标题"实在，但慢 |
| **关注关键词** | 可加多个；留空用内置那几组。带空格的关键词（如 `DeepSeek Harness`）没问题 —— 逗号或回车才断一个 |
| **私信发给谁** | 可加多个 UID（一轮给每人各发一条）；选「只私信」时用 |
| **人格设定文件** | ⭐ **整个插件唯一的人格来源**，就是一个 md。留空 = 用数据目录里的 `persona.md`；想放别处就填完整路径。**内容在「人格」那一栏直接编辑**。⚠️ 文件不存在或为空 ⇒ 这一轮**没有人格设定**（插件自己不带性格，其余提示词也都不含性格） |
| **跑这一轮用哪个模型** | 服务商 + 模型两栏，**留空就用 profile 自己配的那个**。填了的话，跑每一轮时会生成一份覆盖丢给 dsh —— **只影响这个插件跑的那一轮，不动你的 profile**。⚠️ 只能填字母数字和 `. _ : / -`（要写进配置文件），填了非法字符设置页会当场告诉你「没被采用」 |
| **评论台账** | 已经评论过哪几个视频（**同一个视频不会再发第二条** —— 新评论和楼中楼合起来只算一条）。附一个「清空台账」，只在**那条评论被删了要重发**时才用（要点两下确认） |
| **回复评论（只回楼中楼）** | **默认关**；开了之后展开「每轮最多回几条」—— 只回**直接回复到它那条评论下面的人**，不参与别人的讨论 |
| **日报写多细** | `完整 / 薄版 / 不写`；薄版每条一两行（输出比输入贵 200 倍，薄版省的是真钱） |
| 现在跑一轮 / 装主依赖 / 扫码登录 / 看今天的报告 / 翻报告目录 | 版本号就在这一行上面（**点「检查更新」可以看有没有新版**）。⚠️ 有桌面的机器上会多两个「打开文件夹」按钮；**没有桌面的机器上不显示它们**，换成「翻目录」（见下一节） |

设置页分 **设置 / 报告 / 人格 / 调试** 四栏：

- **报告**：按轮次看今天的日报（不是一整坨糊在屏幕上），有当日概览统计。
- **人格**：⭐ **那个人格文件的编辑器**（看 + 改 + 存），下面再把「这一轮真发出去的话」摊开 ——
  分成「人格设定」和「章程」两段，每段能看全文、能复制。**它到底收到了什么，不用猜。**
- **调试**：实时看这一轮跑到哪了（每次工具调用都有记录，失败标红），
  以及这一轮的提示词原文、实际用的模型、生成的 overlay 原文。

> 列表类的项（关键词 / 要 @ 谁 / AI 识别词 / 私信 UID）都是**标签**样式：回车或逗号添一个，点 × 删掉，
> 粘一串进来会自动拆开。

## 在 Linux / 服务器上（**没有桌面**的机器）

这套东西一开始是照着 Windows 上的 dsh 写的，到 Linux 上有过**整条路走不通**的事故，现在两边都能用了：

- **不再写死某个平台的命令**：`python` 在多数 Linux 发行版上压根不存在（只有 `python3`），
  原来直接写 `python` ⇒ **扫码画不出二维码、内部 MCP 也起不来**。现在按
  `设置里写的 → 自己建的 venv → python3 → python` 依次找。
- **一键升级**原来硬编码 `cmd.exe /c` ⇒ Linux 上必然失败。现在把 shell 交给系统自己决定。
- **找 `dsh`** 原来只猜几个固定路径 ⇒ 装在 nvm / `.npm-global` 下就找不到、还会**静默失败**。
  现在按 `设置 → 正在跑的那个宿主进程自己 → PATH → 从 node 位置推` 来找，不猜安装布局。
- ⭐ **「打开文件夹」在服务器 / NAS 上本来做不到**（那儿没有桌面，`xdg-open` 之类一个都没有）——
  原来只会回一句"这个按钮目前只做了 Windows"。现在**没有桌面就把目录列在设置页里**：
  点目录进下一层、点文件看内容、每份都能下载。
- 安装说明里凡是"只在 Windows 上成立"的说法，都配了 Linux / macOS 的对应写法。

## 红线（写死在提示词里，不靠自觉）

- 不透露你的隐私：账号、机器路径、你聊过的话 —— 一个字都不进评论
- 每轮最多一条评论；同一视频只评论一次；不刷屏、不吵架
- 不确定的事**不编**（报告里如实写「没查到」）

## 它是怎么跑的

- 插件**内部**起一个 Python MCP（下面那个开源项目，已内置），把它的能力注册成 DSH 工具
- 定时到点 → 起一个 headless dsh 会话，把 `prompts/duty.md`（它一轮要做的事）+ 当天设置交给它
- 那一轮的**工作目录 = 插件自己的数据目录**（它被沙箱关着，只写得了自己那一亩三分地）
- ⭐ **人格只有一个来源**：你那个人格文件由插件读进来、内联进提示词 ⇒ **它按你的设定说话**，
  而不是用一套通用人格。插件自身**不带任何性格**，也没别的地方会塞性格进来
- ⭐ **模型**：设置里填了就在生成的 overlay 里覆盖 `agent-default-model`，那一轮生效、别处不受影响
- ⭐ **两道防重复的闸**（都是"别重复打扰真人"）：
  - **一轮只能跑一个** —— 已经有一轮在跑时，再点「现在跑一轮」会被直接拒绝
    （同时跑两轮会重复发评论）。宿主重启过也认得出来（有锁文件在探活）
  - **同一个视频只发一条评论** —— 发评论前先查台账，评论过的直接拒发，
    并把记着的那条一起告诉你；设置页可以看、可以清

## 如果你是一个 AI 助手，正在帮用户装这个插件

按顺序来，别跳步：

1. **先确认前提**：机器上有 `Python 3.10+` 或 `uv` 吗？
   ⚠️ 查 Python 时 **Linux / macOS 上多半是 `python3 --version`**（很多发行版压根没有 `python`）——
   插件自己会按 `python3` → `python` 的顺序找，你不用替它操心 ✓
   两个都没有 ⇒ **建议装 `uv`**（单文件、免管理员、能自带 Python）；
2. **装插件**：`dsh plugin --profile web add github:c1overzz/dsh-bili-scroll`
   （npm 上的 `dsh-bili-scroll` 同名同内容，审核通过后用 `add dsh-bili-scroll` 更省事）
3. ⚠️ **必须提醒用户重启一次 dsh** —— bundle 层要重启才组装，不重启插件不会生效；
4. 重启后请用户进 **设置 → 刷B站**：先点「**装依赖**」（几十秒，进度就显示在页面下面）、再点「**扫码登录**」
   （手机 B 站扫码，**确认时选"记住我 / 长期"**）；
5. **不要**替用户打开「自动评论并 @ 你」—— 那是拿用户的号说话。要用得让用户自己在设置里填「要 @ 谁」。
